## 1. Project Overview

In property and casualty insurance, policy pricing depends on understanding risk exposure, driver age, and population density. Before any predictive loss model can be built, the raw data must be inspected, documented, and audited for extreme values.

This repository contains a **fully reproducible workflow** for Module 1. Anyone who follows the steps below should be able to regenerate every artifact (CSV files, figures, and printed reports) from scratch on a clean machine.

The project covers:

- Programmatic download of the raw dataset from OpenML
- Structural audit (`df.info()`, `df.describe().T`) and raw boundary checks
- A Business Data Dictionary exported to CSV
- Univariate skewness diagnostics with a domain-driven override for `ClaimNb`
- Pearson correlation audit and annotated heatmap
- Distribution box plots and KDE histograms with written interpretation
- Tukey 1.5 × IQR vs. Z-score outlier comparison on `Density`
- A standalone production script that applies the Tukey filter and saves a cleaned dataset
- A final compiled homework report (PDF)
- A peer verification statement confirming independent reproduction

## 4. Step-by-Step Reproduction Guide

All terminal commands below are run from the **project root folder** (`msba265-module1-ziyanchen/`) unless stated otherwise. Running a script from the wrong folder is the most common cause of `FileNotFoundError`.

### Step 1 – Clone the repository

Open a terminal (PowerShell on Windows, Terminal on macOS/Linux), navigate to the folder where you want the project to live, and run:

```bash
git clone https://github.com/ZiyanChen1/msba265-module1-ziyanchen.git
cd msba265-module1-ziyanchen
```

> Do **not** copy the URL from the browser address bar if it ends in `/tree/master` – Git only accepts the repository root URL shown above.

### Step 2 – Open the project in VS Code

From the same terminal, run:

```bash
code .
```

If `code` is not recognized, open VS Code manually, go to **File → Open Folder…**, and select the `msba265-module1-ziyanchen` folder.

Once the folder is open, launch the integrated terminal with **Terminal → New Terminal** (or `` Ctrl+` ``). All remaining commands are run in this terminal.

### Step 3 – Create and activate a virtual environment

**Windows (PowerShell):**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

If PowerShell refuses to run the activation script ("running scripts is disabled on this system"), run the following once, then activate again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Verify:** the terminal prompt should now begin with `(venv)`. Every later step assumes the virtual environment is active.

### Step 4 – Install dependencies

### Step 7 – Run the production outlier filtering script

Back in the terminal (with `(venv)` active, from the project root):

```bash
python src/clean_outliers.py
```

The script applies the Tukey 1.5 × IQR rule to the `Density` feature:

```
IQR         = Q3 − Q1            = 1,658 − 92 = 1,566
Lower bound = Q1 − 1.5 × IQR     = −2,257
Upper bound = Q3 + 1.5 × IQR     = 4,007
```

Records with `Density` outside `[−2,257, 4,007]` are removed.

## 6. Key Findings Summary

**Raw boundary audit** – no negative or sentinel values were found in the core risk features:

| Feature | Min | Max | Comment |
|---|---|---|---|
| `DrivAge` | 18 | 100 | Valid legal driving age range |
| `Exposure` | 0.0027 | 2.01 | Fraction of a policy year; a few policies exceed one year |
| `BonusMalus` | 50 | 230 | Regulatory index; 50 = maximum discount, >100 = surcharge |
| `Density` | 1 | 27,000 | People/km²; long right tail from urban areas such as Paris |
| `VehAge` | 0 | 100 | 100-year-old vehicles are likely data-entry placeholders |

**Skewness** – `ClaimNb` (5.60) and `Density` (4.65) are extremely right-skewed. The automated rule recommends a log transform for both, but `ClaimNb` is overridden: it is a discrete count with >95% zeros, so `log(0)` is undefined and the correct approach is Poisson regression with `log(Exposure)` as an offset. `Density` is a continuous volume metric and `log1p` is appropriate.

**Correlation** – no feature pair exceeds |r| ≥ 0.85. The only notable relationship is `DrivAge` vs. `BonusMalus` (r = −0.48): older drivers accumulate claim-free years and earn discounts.

**Outliers** – on `Density`, Tukey 1.5 × IQR removes 77,566 records (11.44%) while the Z-score method removes only 15,209 (2.24%). Because the mean and standard deviation are inflated by the right tail, the Z-score threshold sits unrealistically high; the IQR method gives a more robust boundary. Whether to actually drop these records depends on the business use case (nationwide pricing → keep and log-transform; OLS regression → trim; tree-based models → no action needed).

## 7. Troubleshooting

| Problem | Cause & fix |
|---|---|
| `fatal: repository '…/tree/master/' not found` | The clone URL was copied from the browser. Remove `/tree/master` and use the `.git` URL in Step 1. |
| `python` is not recognized (Windows) | Try `py` instead of `python`, or reinstall Python from python.org with **Add Python to PATH** checked. |
| `python3: command not found` (macOS) | Install Python 3 from python.org or with Homebrew: `brew install python`. |
| `Activate.ps1 cannot be loaded because running scripts is disabled` | Run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned` and activate again (Step 3). |
| `ModuleNotFoundError: No module named 'pandas'` (or seaborn, etc.) | `(venv)` is not active, or Step 4 was skipped. Activate the environment and re-run `pip install -r requirements.txt`. |
| `FileNotFoundError: … raw_business_data.csv` when running a script | You are not in the project root, or Step 5 has not been run yet. `cd` to the project root and run `python data/download_data.py` first. |
| Step 5 fails with `IncompleteRead(...)` or hangs for several minutes | The OpenML server dropped the connection. Re-run the command, or use the manual download fallback described under Step 5. |
| Notebook cannot find `../data/raw_business_data.csv` | Step 5 has not been completed, or the notebook was moved out of the `notebooks/` folder. |
| Notebook cells show `ModuleNotFoundError` even though `pip install` succeeded | The notebook is using the wrong kernel. Re-select the `venv` kernel (Step 6, items 2–4) and click **Run All** again. |
| Figures look different from the PDF | Make sure the raw dataset has exactly 678,013 rows. If the OpenML file was partially downloaded, delete `data/raw_business_data.csv` and re-run Step 5. |
